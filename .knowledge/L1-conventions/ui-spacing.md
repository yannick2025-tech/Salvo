# UI 间距规范

> 测试报告页面组件区块之间的间距统一标准。

## Component Gaps

- 测试报告页面所有组件区块之间统一 `margin-bottom: 16px`
- 包括：metrics-row、charts-row、charts-section、nodes-section
- 同行内元素间距由 grid gap 控制（16px）
