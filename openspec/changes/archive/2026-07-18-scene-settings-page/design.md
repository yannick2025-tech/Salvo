## Context

当前 `SceneDetailPage.vue` 中场景设置以右侧 Drawer（440px 宽）打开，内含基本信息、场景变量、数据源(CSV) 三部分纵向堆叠。当变量数量超过 5-6 个时，CSV 配置区域被完全推出可视区域，且 Drawer 无独立滚动分区，导致内容不可达。

现有实现：Drawer 通过 `showSettings` ref 控制显隐，内容直接写在 SceneDetailPage 模板中。变量/数据源的 CRUD API 已完备，无需新增后端接口。

## Goals / Non-Goals

**Goals:**
- 将场景设置从 Drawer 改为独立全页面，路径 `/scenes/:id/settings`
- 采用左导航 + 右内容双栏布局，三个分区（基本信息/场景变量/数据源）可独立展示
- CSV 数据源支持内联表格编辑器（分页、inline 编辑、行列增删）
- 完全兼容深色/浅色主题，使用既有 CSS 变量

**Non-Goals:**
- 不改变任何后端 API
- 不重构变量/数据源的 CRUD 逻辑（仅搬迁到新页面）
- 不新增场景设置的数据持久化方式
- 不做移动端专项适配（仅基本响应式）

## Decisions

### 1. 独立页面 vs 抽屉内滚动
**选择**: 独立页面（方案 B）
**理由**: 抽屉内加滚动条（方案 A）仍是临时方案，变量多时体验依然差。独立页面空间充裕，后续可扩展更多设置项，且 URL 可直达、支持浏览器前进后退。

### 2. 左导航 Tab vs 顶部 Tab
**选择**: 左侧垂直导航（200px 宽）
**理由**: 设置页分区数量固定（3 个），左侧导航信息密度高，可展示图标+文字，与右侧内容形成清晰主从关系。顶部 Tab 在宽屏下浪费垂直空间。

### 3. CSV 编辑器：内联展开 vs 弹窗
**选择**: 内联展开
**理由**: 数据源卡片点击后，表格编辑器在卡片下方展开，用户可同时看到数据源列表和编辑内容。弹窗会打断上下文。编辑器 max-height 380px + 内部滚动，不影响页面布局。

### 4. 路由结构
**选择**: `/scenes/:id/settings`，复用既有 `sceneStore` 加载数据
**理由**: 语义清晰，与 `/scenes/:id` 同层级，sceneStore 已有 `fetchSceneById` 方法可直接复用。

## Risks / Trade-offs

- [ Drawer 移除后回退路径丢失 ] → 保留"返回场景"按钮，使用 `router.back()` 或 `router.push('/scenes/:id')`
- [ 页面跳转导致场景详情页状态丢失 ] → sceneStore 已持久化场景数据，页面刷新后通过 route param 重新加载，无状态丢失风险
- [ CSV 编辑器分页性能 ] → 默认 50 行/页，最大 200 行/页，单页数据量可控
