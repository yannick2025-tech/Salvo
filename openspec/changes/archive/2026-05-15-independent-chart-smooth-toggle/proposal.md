## Why

当前 Dashboard、测试报告详情页和导出的 HTML 报告中，图表的平滑/阶梯切换功能存在两个关键问题：(1) 部分图表缺少平滑/阶梯切换按钮，导致用户体验不一致；(2) 所有图表共用同一个 chartType 状态变量，点击任意一个图表的切换按钮会导致整个页面的所有图表同时切换，无法独立控制每个图表的显示样式。这严重影响了用户对单个图表数据展示方式的精细化控制需求。

## What Changes

- **统一添加切换按钮**：为 Dashboard 和报告页面中所有折线图（QPS 趋势、延迟趋势、错误率趋势等）添加平滑/阶梯切换按钮，确保视觉一致性
- **独立状态管理**：将每个图表的 chartType 从全局共享变量改为独立的状态（每个图表维护自己的 smooth/step 状态），实现真正的独立切换
- **节点图表独立化**：多个节点详情图的切换状态互相独立，不再联动
- **导出报告同步优化**：确保导出的 HTML 报告中每个图表都有独立的切换功能，且与在线页面行为一致

## Capabilities

### New Capabilities
- `independent-chart-toggle`: 定义图表独立切换的行为规范，包括每个图表应具备的切换能力、状态隔离要求、以及 UI 一致性标准

### Modified Capabilities
- `report-export`: 导出 HTML 报告中的图表切换功能需要同步更新，确保离线报告也支持独立切换

## Impact

- **前端组件**：DashboardPage.vue、ReportDetailPage.vue 的图表渲染逻辑和状态管理
- **导出模板**：report_generator_enhanced.go 中的 JavaScript 代码和 HTML 结构
- **状态管理**：从单一 ref 变量改为 Map 或对象结构存储每个图表的独立状态
- **用户体验**：用户可以针对每个图表单独选择最适合的数据展示方式（平滑曲线或阶梯线）
